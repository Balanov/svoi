# Безопасность «Своего»

## Сообщить об уязвимости

Используйте закрытый Security Advisory в GitHub-репозитории. Не публикуйте резюме, документы, ключи сертификата, переписку или другие персональные данные в открытых issues.

## Границы данных

- Локальное состояние шифруется средствами ОС через Electron `safeStorage`; доступ ограничен текущим пользователем устройства.
- Выбранные документы обрабатываются на ПК. Облачная передача их содержимого приложением не предусмотрена.
- Поиск вакансий обращается к открытым данным HH.ru. Сайт может изменить разметку, ограничить запрос или потребовать проверку человеком; приложение не обходит такие ограничения.
- Локальная модель используется только после явного включения. Если уже настроена Ollama, приложение обращается к локальному сервису.
- Сертификат отправляет на сервер только псевдоним, статус и счётчики после отдельного согласия.

## Реализованные ограничения

- Electron: `contextIsolation`, `sandbox`, отключённый Node integration и безопасное открытие внешних ссылок.
- Ограничения размеров документов, сообщений, списков и серверных запросов.
- Белый список полей сертификата и отдельный случайный ключ владельца; на сервере сохраняется хэш ключа.
- Повторное согласие для новой публичной ссылки.
- Ограничение частоты создания и изменения сертификатов на стороне PHP.
- Закрытый каталог серверных записей вне `public_html`; публичные страницы получают `noindex` и `no-store`.

## Важные ограничения

- Шифрование хранилища не заменяет защиту учётной записи Windows, резервное копирование и актуальные обновления системы.
- Публичную ссылку видит любой, кому она передана. Не указывайте в псевдониме данные, которые не хотите раскрывать.
- Счётчики показывают действия в приложении, а не квалификацию, трудовой стаж или достоверность заявлений пользователя.
- Локальный характер обработки не является гарантией безопасности всей системы или сторонних зависимостей.
- Установщик Windows пока не подписан Authenticode.
